# Bizel Research

A public project page for **Bizel Research**, a one-person, read-only research prototype by Victor. It describes the case study and can be used as a public “source or platform” link.

The site is static: open `index.html` in a browser, or serve the folder with any static host. There is no build step and no third-party analytics or trackers.

## What’s on the page

- A short introduction to the prototype and how it is used
- Features: public Reddit reader, predicted opportunity scoring, Grok reply drafts, and local draft saving
- Safety and ethics, including initial observation communities
- A note that the full project source is available on request
- Contact: mochiai45@gmail.com and u/BizelResearch

## Typography

Body copy uses **Inter**. Headlines use **Instrument Serif**. Both are SIL Open Font License typefaces, self-hosted under `assets/fonts/` (with license files in that folder).

## Accessibility

The layout is responsive, keyboard accessible, and uses a dark palette aimed at WCAG AA contrast. Scroll-reveal animation is disabled when `prefers-reduced-motion` is set.
